## **📥 Installation & Setup**

### **Prerequisites**

- Node.js (v16+)
- npm / yarn
- Android Studio (for Android)
- Xcode (for iOS)
- A physical device or emulator (Android/iOS)

### **1. Clone the Repository**

```bash
git clone https://github.com/coderyash-ai/My-First-Mobile-App.git
cd My-First-Mobile-App
```

### **2. Install Dependencies**

```bash
npm install
# or
yarn install
```

### **3. Run the App**

#### **For Android**

```bash
npx react-native run-android
```

#### **For iOS**

```bash
npx react-native run-ios
```
